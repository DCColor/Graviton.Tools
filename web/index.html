FLIP
$99 — Perpetual License

Delivery metadata, fixed instantly. Flip rewrites color tags, HDR10 metadata, channel declarations, timecode, and chapter markers directly in the container — no re-encoding, no round-trips through an NLE, no quality loss. A 90-minute master saves as fast as a 30-second clip.

Color space tags (NCLC/CICP) — set, fix, or add them to files that carry none. Catches the 1·2·1 pattern Resolve writes on certain exports
HDR10 static metadata — add mastering display and MaxCLL/MaxFALL to graded masters that ship without it. No re-export
Channel layout declarations — declare 5.1 and 7.1 in MOV and MXF, so an NLE routes them instead of dropping six loose mono tracks
MOV, MP4, and MXF — delivery files and mezzanine masters alike
Timecode — read and rewrite start timecode in place, or add a timecode track to a file without one
Chapter markers — edit titles or mark them from the built-in player
Batch a whole folder — file queue plus saved presets for audio config and color tags
Built-in player with per-channel audio stats before delivery
